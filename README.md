# GetAgentCap API

Spend caps and alerts for any agent or bot wallet — EVM (Base) and Solana, x402 supported but not required.

Point it at a wallet address, get a live USDC spend ledger, budget thresholds, and alerts. No SDK needed — this repo is the OpenAPI spec for the public API.

- Product: https://getagentcap.com
- Spec: [openapi.yaml](openapi.yaml)
- Free to try, 5-minute setup, no card required.

## Use case

Built for anyone running autonomous agents or bots that spend from a wallet — AI agent frameworks, trading/ops bots, treasury hot wallets — where "did my bot just drain the wallet overnight" is a real risk.
